# スズリ (Suzuri)

日本語の文を一文まるごとローマ字で打ち、マウスで文節と候補を直して、クリップボードに入れる（または元の入力欄に貼り付ける）デスクトップツールです。

- ショートカットで画面中央にオーバーレイを出す
- 上段にひらがなとピン（文節の区切り）、下段に変換結果を表示し、打つそばから変換する
- ピンをドラッグして文節を伸縮し、文節の上でホイールを回して候補を切り替える
- Enter でクリップボードに入れる。Tab で「呼び出し元に貼り付けまで行う」モードに切り替えられる
- 変換は Mozc の辞書を使って手元だけで行う。通信はしない

## 操作

| 操作 | 結果 |
|---|---|
| `Alt+J`（macOS は `Option+J`。トレイの「設定…」で変えられる） | 新しく入力する |
| `Alt+Shift+J` | 前回の状態を呼び戻して直す |
| ローマ字を打つ | ひらがなで入り、打つそばから変換する |
| `Shift` + 英字 | 英字をそのまま入れる（既定は大文字。トレイの「設定…」で小文字にできる。ホイールで大文字・小文字・全角に切り替え） |
| `Space` | 半角スペースを入れる（全角はホイールで選ぶ） |
| ピンをドラッグ | 文節の区切りを動かす |
| 文字の間を右クリック／ピンを右クリック | ピンを足す／消す |
| 文節の上でホイール | 候補を切り替える |
| `Ctrl` + ホイール | スクロールする |
| `Tab` | Enter の動き（コピー／貼り付け）を切り替える |
| `Enter` | 確定する |
| `Esc` | 閉じる |

選んだ候補は学習し、次から上に出します。学習はトレイメニューから消せます。
ログイン時に起動するかどうかと、配色（OS に合わせる・ライト・ダーク）も、トレイメニューで切り替えられます。
文字の大きさと背景の不透明度は、トレイの「設定…」で変えられます。
画面は上の中央の横棒・余白・下の案内の欄をドラッグして動かし、縁をドラッグして大きさを変えられます。次からは同じ位置・大きさで出ます。上の横棒をダブルクリックすると画面の中央に戻ります。

## ビルド

Rust（stable）と Node.js が必要です。

```sh
npm install
# Mozc の辞書を取得してバイナリ辞書を作る（初回のみ。取得元のコミットとハッシュ値は固定している）
cargo run -p suzuri-dictgen --release
# 開発モードで起動
npx tauri dev
# 配布用にビルド
npx tauri build
```
