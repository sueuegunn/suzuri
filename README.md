<h1 align="center">Suzuri</h1>

日本語の文を一文まるごとローマ字で打ち、マウスで文節と候補を直して、クリップボードに入れる（または元の入力欄に貼り付ける）デスクトップツールです。

- ショートカットで画面中央にオーバーレイを出す
- 文節ごとに、ひらがな（とピン＝文節の区切り）の下にその変換結果を並べ、打つそばから変換する
- ピンをドラッグして文節を伸縮し、文節の上でホイールを回して候補を切り替える
- 長い語（「あにめー」→「アニメーション」）は、打っている途中で続きを薄く出し、Tab で採れる
- Enter でクリップボードに入れる。右下の表示を押すと「呼び出し元に貼り付けまで行う」モードに切り替えられる
- 変換は Mozc の辞書を使って手元だけで行う。通信はしない

## 操作

| 操作 | 結果 |
|---|---|
| `Alt+J`（macOS は `Option+J`。トレイの「設定…」で変えられる） | 新しく入力する |
| `Alt+Shift+J` | 前回の状態を呼び戻して直す |
| ローマ字を打つ | ひらがなで入り、打つそばから変換する |
| 上の「a」「あ」を押す／`無変換`・`変換`（macOS は `英数`・`かな`）／`半角/全角` | 英数モード（打ったとおりに入れる）とかなモードを切り替える |
| `Shift` + 英字 | 大文字の英字を1文字入れる（ホイールで大文字・小文字・全角に切り替え） |
| `Space` | 半角スペースを入れる（全角はホイールで選ぶ） |
| `Shift+Enter` | 改行を入れる |
| `Ctrl+V`（macOS は `Cmd+V`） | クリップボードの文字をそのまま貼り付ける |
| ひらがなや変換結果の上を左クリック／`←` `→` `↑` `↓` `Home` `End` | 入力カーソルを動かす |
| `Backspace`・`Delete` | カーソルの前・後ろの1文字を消す |
| `Ctrl+Backspace`・`Ctrl+Delete`（macOS は `Option`） | 文節の区切りまでまとめて消す |
| ピンをドラッグ | 文節の区切りを動かす |
| ピンをクリック | ピンの位置に入力カーソルを置く |
| 文字の間を右クリック／ピンを右クリック | ピンを足す／消す |
| ひらがなの文字やピンを右ボタンでドラッグ | 選んだ範囲を1つの文節にし、まわりを区切り直す |
| 変換結果の文節を右クリック／右ボタンでドラッグ | その文節（ドラッグならまたいだ文節をつないだもの）を今の表記のままユーザー辞書に登録する。出てくる知らせを5秒以内に左クリックすると取り消せる |
| 変換結果の文節を左ダブルクリック | 今の変換結果をひらがなの側にそのまま書き込む（「明るい」を書き込んで「るい」を消し、読みを知らない「明」だけを残す、など） |
| 文節の上でホイール | 候補を切り替える |
| 文節にマウスを乗せて `F6`〜`F10` | ひらがな・全角カタカナ・半角カタカナ・全角英数・半角英数にする |
| `Ctrl` + ホイール | スクロールする |
| `Tab` | 薄く出ている続き（長い語の残り）を採る |
| 右下の「コピー」「貼り付け」を押す | Enter の動き（コピー／貼り付け）を切り替える |
| `Enter` | 確定する |
| `Esc` | 閉じる |

選んだ候補は学習し、次から上に出します。学習はトレイメニューから消せます。
ログイン時に起動するかどうか、配色（OS に合わせる・ライト・ダーク）、呼び出したときの入力モード（かな・英数・IME に合わせる）も、トレイメニューで切り替えられます。
文字の大きさと背景の不透明度は、トレイの「設定…」で変えられます。
人名や社名など辞書にない語は、トレイの「設定…」の「ユーザー辞書」タブで読みと表記を登録すると、変換で1語として出るようになります。登録した語はそのタブで編集・削除できます。読みにはひらがなのほか英数字や記号も使えます。
貼り付けモードでは、貼り付けたあとクリップボードを元の中身に戻します。変換した文を残したいときは、トレイの「設定…」で「貼り付けたあともクリップボードに残す」をオンにします。
画面は上の中央の横棒・余白・下の案内の欄をドラッグして動かし、縁をドラッグして大きさを変えられます。次からは同じ位置・大きさで出ます。位置はモニターごとに覚え、マウスのあるモニターに出ます。上の横棒をダブルクリックすると画面の中央に戻ります。

## インストール

[Releases](https://github.com/sueuegunn/suzuri/releases) から、Windows は `Suzuri_*_x64-setup.exe`、macOS は `Suzuri_*_universal.dmg` を取ってください。
どちらも署名していないため、初回の起動で警告が出ます。進め方は各リリースの説明に書いています。

## ビルド

Rust（stable）と Node.js が必要です。

```sh
npm install
# Mozc の辞書を取得してバイナリ辞書を作る（初回と、辞書の形式が変わったとき。取得元のコミットとハッシュ値は固定している）
cargo run -p suzuri-dictgen --release
# 開発モードで起動
npx tauri dev
# 配布用にビルド
npx tauri build
```
